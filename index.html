Plot Twist Toons

Plot Twist Toons is a YouTube channel that publishes original animated mini-series in vertical Shorts format, starting with The Janitor's Daughter.

About the uploader app

"Plot Twist Toons Uploader" is a private tool used only by the channel owner. It uses the YouTube Data API to upload our own finished episodes to our own channel, set their titles, descriptions and schedules, organize playlists, and read our channel's analytics. It does not access anyone else's account or data.
